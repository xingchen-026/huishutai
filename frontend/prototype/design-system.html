Design System

汇书台概念原型的统一视觉与组件契约：设计令牌、布局骨架、组件用法、交互状态与扩展接口。 新页面只需组合这里的类名与外壳能力，不再重复定义样式。

设计原则

4 条
信息收敛，入口分层高频入口放首页与侧边栏；页面动作 ≤ 3，其余进「更多」或命令面板。
层级清晰，一屏可读页头（标题 + 动作）→ 概览指标 → 主内容 → 说明；卡片间距 18px。
统一令牌，禁止硬编码颜色、字号、间距、圆角、阴影全部引用 tokens.css 变量。
扩展优先新页面注册导航与命令即可接入，外壳、组件与交互不重复实现。

导航与扩展接口

避免按钮与页面堆积

所有页面共享同一套外壳：导航、命令面板、页面动作栏与通用交互都由 assets/js/shell.js 提供。 新页面不修改外壳代码，只通过下面四个扩展点接入。

页面与操作统一搜索，Ctrl / Cmd + K

防堆积规则

页面数量增长时，先做信息架构，再谈按钮位置

场景 做法 不要这样
同一页面操作变多 常驻 ≤ 3 个（主操作 + 2 个次操作），其余进「更多」下拉 横向排 6+ 个按钮
功能模块变多 侧边栏按领域分组（内容 / 模型 / 智能应用 / 系统），组内可折叠 全部平铺成一级导航
页面入口高频 首页应用入口 + 命令面板（Ctrl + K） 顶栏堆满快捷按钮
页面内部层级多 页内 Tabs / 分段控件 / 抽屉下钻 再开一个新页面放按钮
非当前能力 用「规划中」占位页 + 路线图说明，按钮置灰 提前放半成品入口

Do / Don't

Do：一页一个主任务页头只放与当前页面直接相关的操作；跨页面动作交给首页入口或命令面板。
Don't：把页头当工具栏筛选、批量操作放内容区 toolbar；页头动作保持克制。
Do：状态用语义色 + 文案颜色只辅助，必须同时给出文字（如「待验证」「需登录」）。
Don't：用颜色表达装饰等级卡片、正文不使用高饱和色；强调只给主操作与关键数据。
Do：空态、失败态、加载态一起设计列表 / 详情页至少准备空状态与失败提示，避免空白屏。
Don't：页面内重复造组件按钮、表格、弹层只用共享类；特殊样式写页面作用域并注明原因。
